# MORDHAU Ukrainian Localization

Українська локалізація для MORDHAU на Windows.

## Встановлення

1. Закрийте гру.
2. Розпакуйте архів у будь-яку папку.
3. Запустіть `Install-Mordhau-UA.bat`.
4. Запустіть MORDHAU.
5. У налаштуваннях гри виберіть мову `Українська`.
6. Перезапустіть гру, якщо мова не змінилася одразу.

## Видалення

Запустіть `Uninstall-Mordhau-UA.bat`.

## Сумісність

Збірка зроблена для Windows-версії MORDHAU. Має працювати зі Steam та Epic Games, якщо версія гри сумісна з цими файлами локалізації.

Після великих оновлень гри переклад може потребувати оновлення.

## Примітка

Якщо під час встановлення з'явиться помилка, вікно залишиться відкритим. Скопіюйте текст помилки й повідомте про неї.
